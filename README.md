# Crypto Analytics — демо приложения

Веб-версия приложения Crypto Analytics: можно потыкать экраны в браузере.

**Открыть:** https://wolllipp.github.io/crypto-analytics-demo/

- Расчёты и цены — настоящие, с сервера проекта (модель диапазона BTC на 7 дней).
- Начните с песочницы: виртуальные $1 000, без почты и регистрации.
- Это аналитика, а не инвестиционная рекомендация. Приложение не хранит деньги и не совершает сделки.

Здесь лежит только собранная веб-версия. Исходный код и исследования — в закрытом репозитории проекта.
Сайт проекта: https://cryptoto.site
